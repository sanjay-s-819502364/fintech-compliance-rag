# Source Documents

This project does not host or redistribute any regulatory PDFs. Documents are
sourced directly from the FCA and ASIC's own websites — download them
yourself into a local `corpus/` folder (gitignored) before running ingestion.

If any link below has moved, search the document title or reference number
directly on the regulator's site — both maintain permanent document finders
(linked at the bottom of each section) that are more durable than any single
URL.
